## Project Overview

This submission contains three responsive, static website projects
created using **HTML5 and CSS3 only**. No JavaScript is used.

### 1. Personal Portfolio Website

-   File: `activity1.html`
-   Sections: Home, About, Skills, Projects, Education and Contact
-   Design: Purple accents and a light pastel background

### 2. Northstar College Website

-   File: `activity2.html`
-   Sections: Home, About, Courses, Facilities and Admissions
-   Design: Navy blue, blue and gold
-   Features: Hero section, statistics, course cards, facilities and
    admission contact link

### 3. Crumb & Co. Bakery Website

-   File: `activity3.html`

## Technologies

-   HTML5 for page structure and content
-   CSS3 for layout, colours, typography, hover effects and responsive
    styling
-   CSS Flexbox and Grid for page layout
-   CSS media queries for smaller screens
-   Anchor links for section navigation

## How to Run

1.  Keep the three HTML files in a folder.
2.  Open the folder in Visual Studio Code, or open an HTML file directly
    in a web browser.
3.  Recommended filenames:
    -   `activity1.html` --- Personal Portfolio
    -   `activity2.html` --- Northstar College
    -   `activity3.html` --- Crumb & Co. Bakery
4.  To preview in Visual Studio Code, use Live Server / Live Preview if
    installed.
5.  An internet connection is needed for the externally hosted
    photographs.

## Notes and Limitations

These are front-end demonstration websites. They do not include a
server, database, user authentication, real admissions form processing
or online ordering functionality. Email buttons use `mailto:` links and
require a configured email application.
